# Event Logger - Renewed

A Starsector 0.98.5a utility mod. Every message of the fleet log (the messages at the bottom left of
the campaign screen that fade after a while) is kept on a new **Events** tab of the Intel screen.

## What it does

- Open the Intel screen and press **Events** (next to Intel, Planets and Factions; its number key is shown on
  the button).
- Messages are listed newest first, each with its icon, date, title and the lines the message showed.
- **Search** filters the list as you type.
- **Clear** empties the log. Click it twice.
- **Show** opens the message's entry on the Intel screen, while that entry is still there.
- The log is saved with the campaign. The newest 2000 messages are kept.

## Requirements

- Starsector 0.98.5a. No other mods needed.
- Do not use it together with the original Event Logger: both add an Events tab.

## Install

Install `EventLoggerRenewed.zip` from the
[latest release](https://github.com/andrzejsokolowski/starsector-event-logger-renewed/releases/latest) with your
mod manager, or unpack it into `Starsector/mods`.

Safe to add to a game in progress. Safe to remove: the save only holds the log as plain text.
